# 我的维度

Forge 1.20.1 模组，添加裂罅物品与多个心境维度。

## 内容

- 裂罅：Shift + 右键打开动作轮盘；选择后，普通右键执行当前动作。
- 配方：4 个黑色带釉陶瓦按上下左右十字形摆放，中间留空。
- 空灵心境：超平坦维度，底部 60 层石头、3 层泥土、3 层石英块。
- 镜之心境：使用与主世界相同的地形生成配置和世界种子。
- 水之心境：底部 20 层石头、5 层砂砾、50 层水。
- 自然心境：草原超平坦，50 层石头、9 层泥土、1 层草方块。
- 维度限制：心境维度内不会自然生成生物；在心境内的玩家不能被其他玩家用 `/tp` 或 `/teleport` 传送。

## 构建

```powershell
.\gradlew.bat build
```

构建完成后的 jar 位于 `build/libs/`。
